# Anshaditya Sharma Portfolio

A self-contained portfolio website built from the provided resume, LeetCode links, and GitHub repositories.

## Run

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - responsive visual system, layout, and animation styling
- `script.js` - project filtering, details modal, card motion, reveal animation, and canvas background
